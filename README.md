# incident-tracker-angular

Sistema web desarrollado en Angular para registrar, clasificar y dar seguimiento a incidentes técnicos.

## Objetivo
Gestionar incidentes técnicos usando GitHub Issues y Projects como flujo de trabajo colaborativo.

## Flujo de trabajo
1. Registrar incidente como Issue usando la plantilla
2. Clasificar con etiquetas (tipo, prioridad, módulo)
3. Mover el ticket en el tablero Kanban según avance
4. Cerrar el issue con evidencia técnica
